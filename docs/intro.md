# Introduction

Welcome to the Physical AI & Humanoid Robotics textbook. This comprehensive resource covers the essential concepts needed to understand and implement humanoid robotics systems, from simulation to real-world deployment.

## Overview

This textbook is structured into 4 core modules:

1. **Module 1: The Robotic Nervous System (ROS 2)** - Learn the fundamentals of Robot Operating System 2
2. **Module 2: The Digital Twin (Gazebo & Unity)** - Explore simulation environments for robotics
3. **Module 3: The AI-Robot Brain (NVIDIA Isaac™)** - Understand AI-driven robotics systems
4. **Module 4: Vision-Language-Action (VLA)** - Master the integration of perception, reasoning, and action

Each module is designed to build upon the previous, creating a comprehensive learning path for engineering students with Python and basic robotics knowledge.

## Getting Started

Begin with Module 1 to establish a strong foundation, then progress through each module sequentially. Each module contains weekly breakdowns with learning objectives, practical exercises, and assignments.
