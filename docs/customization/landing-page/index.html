Landing Page Customization

Overview​

The landing page for the Physical AI & Humanoid Robotics textbook features a modern, animated design with interactive elements. It showcases the four core modules with animated feature cards and provides clear pathways for users to start learning.

Components Structure​

The landing page is built with several custom React components:

  • src/pages/index.js - Main homepage component with hero section and layout
  • src/components/HomepageFeatures/index.js - Container for feature cards
  • src/components/FeatureCard/index.js - Individual feature card component with animations
  • src/components/CtaButton/index.js - Custom button component for calls-to-action

Color Scheme​

The landing page uses a professional color palette:

  • Primary Background: #1e293b (slate-900)
  • Text: #ffffff (white)
  • Accent: #4f46e5 (indigo-600)
  • Highlights: #22d3ee (cyan-400)

Feature Cards​

The four feature cards represent the core modules:

  1. ROS 2 - Robotic Nervous System (Brain icon)
  2. Digital Twin - Simulation environments (Globe icon)
  3. AI-Robot Brain - Intelligent control systems (CPU icon)
  4. Vision-Language-Action - Embodied AI applications (Eye icon)

Each card includes:

  • Technical SVG icon from Lucide React
  • Hover effects with scale and shadow transformations
  • Staggered reveal animations on scroll using GSAP
  • Direct link to the respective module documentation

Animations​

Animations are implemented using GSAP with ScrollTrigger:

  • Cards fade in and slide up as they enter the viewport
  • Staggered delays create a sequential reveal effect
  • Smooth transitions enhance user experience
  • Reduced motion support for accessibility

Responsive Design​

The landing page is responsive across device sizes:

  • Mobile (up to 768px): Single column layout, stacked buttons
  • Tablet (768px - 1024px): Responsive grid adjusts based on screen width
  • Desktop (1024px+): Multi-column grid layout with optimal spacing

Accessibility Features​

The landing page includes accessibility features:

  • ARIA labels for interactive elements
  • Keyboard navigation support
  • Reduced motion preferences respected
  • Semantic HTML structure
  • Proper heading hierarchy
  • Sufficient color contrast

Customization Options​

Changing the Value Proposition​

Update the subtitle in src/pages/index.js:

<p className="hero__subtitle">Build the future of embodied AI</p>

Modifying Feature Cards​

Edit the FeatureList array in src/components/HomepageFeatures/index.js:

const FeatureList = [
  {
    title: 'New Title',
    icon: NewIcon, // Import the new icon from lucide-react
    description: 'Updated description',
    link: '/docs/new-module/path',
  },
  // ... other features
];

Updating Color Scheme​

Modify the CSS variables in:

  • src/pages/Homepage.module.css - Hero section styles
  • src/components/FeatureCard/styles.module.css - Feature card styles
  • src/components/CtaButton/styles.module.css - Button styles

Performance Optimization​

  • GSAP is loaded dynamically only on the homepage to optimize bundle size
  • CSS Modules provide scoped styling without global conflicts
  • SVG icons are tree-shaken to include only used icons
  • Animations are optimized for 60fps performance

Troubleshooting​

Animations Not Working​

  1. Check that GSAP and ScrollTrigger are properly imported
  2. Verify that the animation code runs only in the browser environment
  3. Ensure no SSR errors occur during build

Responsive Issues​

  1. Verify CSS media queries are correctly implemented
  2. Test on various screen sizes and orientations
  3. Check that touch devices work properly with hover effects

Accessibility Issues​

  1. Run accessibility audits using tools like axe-core
  2. Verify keyboard navigation works for all interactive elements
  3. Test with reduced motion preferences enabled
